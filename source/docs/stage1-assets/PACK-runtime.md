# runtime delivery subset

This ZIP is independently extractable, not a multipart archive. It contains only the files listed in CHECKSUMS-runtime.json. No media was re-encoded for this split.

Runtime pack: web-ready images/audio plus documents, licenses and measurements. Masters pack: original generated image PNGs, rendered WAVs, preparation/composition scripts and audition excerpts. Sample-sources pack: all 7 original CC0 WAV recordings plus exact source provenance and license texts.

Extract the three packages into the same parent directory to reconstruct the asset collection. Shared metadata is identical. The full original 23,169,875-byte ZIP remains unchanged in Library. References in the original documentation to masters/sources refer to the complete collection, NOT a claim they exist in every subset. Runtime alone is sufficient for integration; masters + sample-sources support reproducibility.

Actual game files, private URLs, credentials and X materials are not included. All original QA limitations remain.
