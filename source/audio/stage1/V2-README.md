# 星返し SE v2 delta candidate
2026-10-23 UTC. SE only. Previous BGM, v1 assets and game remain unchanged.

Three keys: capture / rebound / hit. WAV masters are 44.1kHz stereo PCM16. Runtime contains OGG and MP3. Master durations: 0.27 / 0.95 / 0.42 seconds respectively. Peak targets remain the v1 values (-10 / -4 / -7 dBFS), not an across-the-board volume increase.

Design: rebound uses recorded timpani resonance, woody marimba midrange, cello pizzicato contact, a restrained upward sparkle and short non-circular room. Hit is a dry percussive knock without reward notes. Capture keeps its quiet rounded sparkle. Rebound/hit use restrained saturation to retain audible body behind the transient. This is sampled acoustic percussion plus original sound design, not an entirely live recording.

Integration: starting gains capture .45, rebound .65, hit .65, BGM .55. Coalesce capture events (~80ms), protect hit/rebound voices from capture replacement. Existing mute and audio-unlock behavior must remain. These gain values require real in-game listening; do not claim they are final. Short OGG decode count is 128 frames shorter than master in ffmpeg; use actual decoded duration and do not loop SE.

Reproduction: python render_se.py --sources PATH_TO_ORIGINAL_PACK/audio-pack/sources . Requires Python3/numpy/scipy/ffmpeg(libvorbis/libmp3lame). ## Additional requested boss music
stage1-boss is a new 112 BPM / E-minor / 16-bar variation on the field motif. Denser 3+3+2 cello/marimba pulse, an octave answering voice, and more frequent recorded timpani accents build pressure; no field music bytes were altered. It is not only an increase in master level: peak remains -5dBFS while orchestration and note placement change. Measured integrated loudness -17.57 LUFS versus the original field -19.13 LUFS. Adjust boss gain slightly below field if a level-matched transition is preferred (.47 versus field .55 is a useful starting point).

BGM loop: exactly 1,512,000 frames at 44.1kHz = 34.285714285714285 seconds; start 0 and exclusive end 1,512,000. OGG decode count matches. MP3 fallback gapless behavior remains unverified. render_boss.py reconstructs boss WAV/OGG/MP3 from the original pack's complete seven raw WAV files. It does not generate or modify field music.

Transition recommendation: begin a 2–4 second equal-power crossfade on a beat or bar boundary where practical, using shared AudioContext scheduling, not independent setTimeout timers. Pause/resume should preserve transition progress. Stop the field node when fade completes; avoid creating several boss loops from repeated phase events. Suggested three-second curve is field*cos(theta), boss*sin(theta), theta from0 to pi/2. Never fade BGM by changing the global gain that also controls SE.

verify_transition.py tested a 3-second equal-power transition at all 64 field beat offsets into the boss downbeat, plus repeated capture/rebound/hit. With both music gains .55 and SE .45/.65/.65, worst peak was -2.85dBFS, no clipped samples. qa/crossfade-stress.json records cases; qa/crossfade-worst-preview.wav is the worst numerical overlap. This is a bounded offline test, not all possible overlaps or an actual browser playback test. Human listening, perceived naturalness, transition timing in game and mobile remain to verify. The old field WAV hash is recorded in manifest.json and matches the original pack ledger.
